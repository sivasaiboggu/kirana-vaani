Sarvam AI voice

With a Sarvam key, the live counter speaks with Saaras (speech-to-text), sarvam-105b (conversation + tool calls) and Bulbul (voice). Without one it uses the free Web Speech API automatically.

The key is stored only in this browser's localStorage — never in the project files, never sent anywhere except Sarvam's API. For a self-hosted deploy you can also put it in sarvam.config.js (copy sarvam.config.example.js) — that file is gitignored. A browser key is visible in devtools, so for a real production shop, proxy Sarvam through a small server instead.

Get a key at dashboard.sarvam.ai — sign up and create an API key.

Settings are per shop — switch shops in the top bar to configure each one. The Sarvam key is shared across shops.
